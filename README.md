## 📌 Client Brief & Business Goal
**Swami Consultancy** (a Pune-based career & placement agency) hired me as a freelance web developer to design and build a high-converting, mobile-first one-page website. 

The client needed an updated web presence to highlight their services (placement assistance, ATS resume building, and interview prep), display student testimonials, and capture prospective student leads directly via WhatsApp and phone.

---

## 🛠️ Tech Stack & Implementation
* **Frontend:** HTML5, CSS3 (BEM layout architecture, Custom CSS Variables), Modern JavaScript (ES6+)
* **Typography:** Google Fonts (`Poppins`, `Inter`)
* **Integrations:** WhatsApp Business API Deep-Linking, Embedded Google Maps API
* **Deployment & Hosting:** Vercel (CI/CD connected to GitHub)
* **Optimization:** WebP image format, SVGs for crisp scaling, lazy loading

---

## 🎯 What I Delivered for the Client

1. **Custom UI/UX Design & Development:**
   * Built a clean, professional gold-and-dark themed UI aligned with the client's corporate brand.
   * Engineered a fully responsive design that works seamlessly across desktop, tablet, and mobile devices.

2. **Lead Generation & Conversion Setup:**
   * Built interactive high-intent Call-To-Action (CTA) buttons that link directly to the client's WhatsApp support line.
   * Built organized sections for Services, Placement Process, Impact Stats (1000+ Students Guided), and Client Testimonials.

3. **Performance & SEO:**
   * Optimized asset loading and font delivery to ensure sub-second page loads.
   * Implemented structured metadata and preconnect directives for local business SEO.

4. **Production Deployment:**
   * Set up continuous deployment pipeline on Vercel for effortless site updates.
